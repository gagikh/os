# Գործնական առաջադրանքներ Linux-ից

Առաջադրանքների ընդհանուր ժողովածու՝ վերցված ամեն օրվա Self-Learning բաժնից։ Ամեն առաջադրանք նշված է այն օրով, որի նյութից է կախված։

Պատասխանների բանալի այստեղ չկա։ Անծանոթ տերմինի համար տես [GLOSSARY.md](GLOSSARY.md)-ը, հրամանների համար՝ [COMMANDS.md](COMMANDS.md)-ը, իսկ տվյալ օրվա առաջադրանքներին անցնելուց առաջ՝ համապատասխան `dayNN/README.md`-ը։

## Օր 1. Linux-ի ներածություն
1. <a id="task-1"></a>Գտիր Linus Torvalds-ի 1991 թ. օգոստոսի 25-ի նամակը `comp.os.minix` խմբին և կարդա այն։ Ի՞նչ architecture-ի համար էր kernel-ը, և ինչ էր նա ասում portability-ի մասին։ *(Օր 1)*
2. <a id="task-2"></a>`man man`. կարդա բաժինների ցանկը։ Գտիր `printf`-ը երեք բաժնում (`man -a printf` կամ `man -k printf`)։ Ինչո՞վ են դրանք տարբերվում։ *(Օր 1)*
3. <a id="task-3"></a>Գործարկիր `cal 9 1752`։ Ինչու՞ են այդ ամսում 11 օր բացակայում։ *(Օր 1)*
4. <a id="task-4"></a>Գտիր քո համակարգի 5 ամենամեծ module-ները. `lsmod | sort -k2 -n | tail -5`։ Յուրաքանչյուրի համար `modinfo -F description`-ով պարզիր, թե ինչ սարքի համար է։ *(Օր 1)*
5. <a id="task-5"></a>Գտիր 3 ծրագիր քո համակարգում և պարզիր դրանց license-ը. `ls /usr/share/doc/bash/` և `cat /usr/share/doc/bash/copyright`։ Ի՞նչ license ունեն `bash`-ը, `openssh-client`-ը և `zlib1g`-ը։ *(Օր 1)*
6. <a id="task-6"></a>Ներբեռնիր Linux kernel-ի կոդի ցանկացած ֆայլ [git.kernel.org](https://git.kernel.org/)-ից և գտիր `SPDX-License-Identifier` տողը։ *(Օր 1)*
7. <a id="task-7"></a>Գրիր `printf ... | nc example.com 80` փորձը, ապա փոխիր `Host:`-ը գոյություն չունեցող անունով։ Ի՞նչ պատասխան տվեց սերվերը և ինչ HTTP կոդով։ *(Օր 1)*
8. <a id="task-8"></a>Տեղադրիր `zsh` և `fish` (`sudo apt install zsh fish`), գործարկիր դրանք և համեմատիր `bash`-ի հետ։ Վերադառնալու համար՝ `exit`։ *(Օր 1)*

## Օր 2. Shell-ը և ծրագրի միջավայրը
9. <a id="task-9"></a>Գրիր ծրագիր, որը տպում է իր բոլոր argument-ները քառակուսի փակագծերում՝ `[a] [b c]`։ Գործարկիր `./args a "b c" *.txt '$HOME' $HOME`-ով և բացատրիր ամեն արդյունքը։ *(Օր 2)*
10. <a id="task-10"></a>Գործարկիր `bash`, նրա մեջ՝ ևս մեկ `bash`, և երրորդ մակարդակում փոխիր `export X=3`։ Դուրս արի (`exit`) և ստուգիր `X`-ը ամեն մակարդակում։ Ամեն մակարդակում տպիր `$$`-ը և `$PPID`-ը։ *(Օր 2)*
11. <a id="task-11"></a>Գրիր C++ ծրագիր, որը տպում է `.`-ներ վայրկյանը մեկ `printf`-ով, ապա `fprintf(stderr, ...)`-ով, ապա `printf` + `fflush`-ով։ Համեմատիր։ Գործարկիր առաջինը `./dots | cat`-ով. ինչ փոխվեց։ *(Օր 2)*
12. <a id="task-12"></a>Գործարկիր `sleep 100`, ապա Ctrl+C։ Ի՞նչ է `$?`-ը։ Նույնը՝ `kill -9`-ով ուրիշ terminal-ից։ Համեմատիր `kill -l`-ի ցանկի հետ։ *(Օր 2)*
13. <a id="task-13"></a>`strace -f -e trace=execve bash -c 'ls | wc -l'`. քանի՞ ծրագիր գործարկվեց, և ով գործարկեց դրանք։ *(Օր 2)*
14. <a id="task-14"></a>Գտիր, թե ինչ ֆայլեր է բացում `ls`-ը, մինչև կհասնի թղթապանակը կարդալուն. `strace -e trace=openat ls 2>&1 | grep -v ENOENT`։ Որո՞նք են գրադարաններ (`.so`), և որո՞նք՝ կարգավորումներ։ *(Օր 2)*
15. <a id="task-15"></a>Գրիր ծրագիր, որը ստեղծում է ժամանակավոր ֆայլ `mkstemp`-ով, գրում է այնտեղ 1 MB, ապա `sleep(30)`։ Մինչ ծրագիրը քնած է, գտիր ֆայլը `lsof -p PID`-ով։ Կրկնիր `unlink`-ով և առանց դրա։ Ի՞նչ է ցույց տալիս `lsof`-ը առաջին դեպքում։ *(Օր 2)*
16. <a id="task-16"></a>Փոխիր `PS1`-ը, որ prompt-ում երևա ժամը և վերջին հրամանի exit status-ը։ Կարդա `man bash`, PROMPTING բաժինը։ *(Օր 2)*

## Օր 3. Ֆայլեր և թղթապանակներ
17. <a id="task-17"></a>Գրիր ռեկուրսիվ `ls` C++-ում. `./tree dir` տպում է բոլոր ֆայլերը և ենթաթղթապանակները՝ խորությամբ, յուրաքանչյուրի inode number-ը, տեսակը (`stat`/`lstat`) և link count-ը։ Symlink-երի համար տպիր թիրախը (`readlink`) և մի մտիր դրանց մեջ։ *(Օր 3)*
18. <a id="task-18"></a>Ստեղծիր ext4 ֆայլային համակարգ ֆայլի մեջ և ուսումնասիրիր այն առանց իրական սկավառակի. `truncate -s 64M disk.img && mkfs.ext4 disk.img && sudo mount -o loop disk.img /mnt`։ Ստեղծիր ֆայլեր, ապա `sudo umount /mnt` և `sudo dumpe2fs -h disk.img`, `sudo debugfs -R 'stat <2>' disk.img`, `sudo debugfs -R 'ls -l /' disk.img`։ *(Օր 3)*
19. <a id="task-19"></a>Նույն image-ում ստեղծիր փոքր ֆայլեր ցիկլով, մինչև ստանաս «No space left on device»։ Համեմատիր `df -h`-ը և `df -i`-ը։ Ինչ վերջացավ առաջինը։ Կրկնիր `mkfs.ext4 -N 100000`-ով։ *(Օր 3)*
20. <a id="task-20"></a>Ստեղծիր ֆայլ, բացիր այն `tail -f`-ով մի terminal-ում, մյուսում ջնջիր `rm`-ով։ Գտիր այն `lsof | grep deleted`-ով։ Ինչպես կարող ես վերականգնել պարունակությունը `/proc/PID/fd/`-ից։ *(Օր 3)*
21. <a id="task-21"></a>Ստեղծիր symlink-երի ցիկլ. `ln -s a b ; ln -s b a ; cat a`։ Ինչ սխալ ստացար։ Գտիր այն `man 3 errno`-ում (`ELOOP`)։ *(Օր 3)*
22. <a id="task-22"></a>Հաշվիր ext2-ի ֆայլի առավելագույն չափը 1 KB և 4 KB block-երով (12 direct + single + double + triple)։ *(Օր 3)*
23. <a id="task-23"></a>Ընդլայնիր template-ի `mini_fs`-ը **double indirect** block-ով։ Որքան է դառնում `kMaxFileSize`-ը։ Ավելացրու թեստ, որը գրում է 100 block։ *(Օր 3)*
24. <a id="task-24"></a>Գրիր C++ ծրագիր, որը կարդում է `stdin`-ը նիշ առ նիշ `getchar()`-ով և հաշվում է բայթերը։ Արդյունքը պահիր `char`-ում, ապա `int`-ում, և փորձիր `printf '\xff' | ./count`-ով։ Ինչո՞ւ `char`-ի դեպքում ցիկլը կանգ է առնում շուտ (կամ չի կանգնում)։ *(Օր 3)*

## Օր 4. Pipe-եր, ֆիլտրեր և ռեգուլյար արտահայտություններ
25. <a id="task-25"></a>Տպիր միայն `/etc`-ի վերջից 20-րդ ֆայլը՝ մեկ pipeline-ով։ *(Օր 4)*
26. <a id="task-26"></a>Հաշվիր, քանի ֆայլ և թղթապանակ կա քո home-ում, որոնք դու կարող ես կատարել (`x` իրավունք owner-ի համար)։ *(Օր 4)*
27. <a id="task-27"></a>`/etc/passwd`-ից տպիր օգտատերերի անունները և shell-երը, դասավորված ըստ shell-ի, և հաշվիր, քանի օգտատեր ունի յուրաքանչյուր shell։ *(Օր 4)*
28. <a id="task-28"></a>Գրիր regex, որը համընկնում է միայն վավեր IPv4 հասցեների հետ (յուրաքանչյուր թիվ 0–255)։ Ստուգիր `grep -E -x`-ով `0.0.0.0`, `192.168.1.1`, `256.1.1.1`, `1.2.3`, `01.2.3.4` տողերի վրա։ *(Օր 4)*
29. <a id="task-29"></a>`sed`-ով CSV ֆայլում փոխիր ամսաթվերը `DD.MM.YYYY`-ից `YYYY-MM-DD` ձևաչափի։ *(Օր 4)*
30. <a id="task-30"></a>Գրիր `awk` ծրագիր, որը `ps aux`-ի ելքից հաշվում է հիշողության ընդհանուր օգտագործումը (`%MEM` սյունակ) ըստ օգտատիրոջ։ *(Օր 4)*
31. <a id="task-31"></a>Համեմատիր `yes | head -1` և `yes > /dev/null & sleep 1; kill %1`. ինչու է առաջինը ավարտվում ինքնուրույն։ `strace -f -e trace=write,kill bash -c 'yes | head -1'`-ով գտիր `SIGPIPE`-ը։ *(Օր 4)*
32. <a id="task-32"></a>Ընդլայնիր template-ը `-o` option-ով. տպել միայն համընկած մասերը (`regmatch_t`, ցիկլով նույն տողում)։ *(Օր 4)*

## Օր 5. Արխիվացում և սեղմում
33. <a id="task-33"></a>Ստեղծիր 100 MB ֆայլ զրոներով (`head -c 100M /dev/zero > z`) և 100 MB պատահական տվյալներով (`head -c 100M /dev/urandom > r`)։ Սեղմիր երկուսն էլ `gzip`-ով։ Բացատրիր արդյունքը։ *(Օր 5)*
34. <a id="task-34"></a>Գրիր RLE սեղմող և բացող ծրագիր C++-ում (`./rle -c < in > out`, `./rle -d < out > back`)։ Ստուգիր `cmp in back`-ով։ Որ ֆայլերի վրա է այն փոքրացնում չափը, որոնց վրա՝ մեծացնում։ *(Օր 5)*
35. <a id="task-35"></a>Համեմատիր `gzip -1`, `gzip -9`, `xz -9`, `zstd -19`-ը `/usr/include`-ի tar-ի վրա. չափ և ժամանակ սեղմելու և բացելու համար։ Կազմիր աղյուսակ։ *(Օր 5)*
36. <a id="task-36"></a>Ստեղծիր արխիվ symlink-ով և hard link-ով (Օր 3)։ Ինչպես է `tar -tvf`-ը ցույց տալիս դրանք։ Քանի անգամ է պահվում hard link-ի պարունակությունը։ *(Օր 5)*
37. <a id="task-37"></a>Ընդլայնիր template-ը. թղթապանակների աջակցություն (`typeflag '5'`, ռեկուրսիվ, Օր 3-ի `opendir`/`readdir`)։ *(Օր 5)*
38. <a id="task-38"></a>Ընդլայնիր template-ը `-x` ռեժիմով. բացել արխիվը, վերականգնել իրավունքները (`chmod`) և ժամը (`utimensat`)։ *(Օր 5)*
39. <a id="task-39"></a>`tar -czf - dir | wc -c`. ինչպես իմանալ արխիվի չափը առանց այն սկավառակի վրա պահելու։ Ինչու է սա կարևոր, երբ սկավառակում տեղ չկա։ *(Օր 5)*

## Օր 6. Bash script-եր
40. <a id="task-40"></a>Գրիր script, որը հաշվում է հաշվիչը environment variable-ներով, ինչպես Օր 2-ի C++ ծրագիրը. `x=10 y=20 ./calc.sh x+y`։ Համեմատիր երկու իրականացումները։ *(Օր 6)*
41. <a id="task-41"></a>Գրիր `backup.sh DIR`, որը ստեղծում է `DIR-YYYY-MM-DD.tar.gz` (Օր 5), պահում է միայն վերջին 7 backup-ները և ջնջում հներին։ *(Օր 6)*
42. <a id="task-42"></a>Գրիր script, որը `/var/log/auth.log`-ից (կամ `journalctl -u ssh`) հաշվում է SSH-ի ձախողված մուտքերը ըստ IP-ի և տպում 5 ամենաշատը (Օր 4)։ *(Օր 6)*
43. <a id="task-43"></a>Գրիր `watch_dir.sh DIR`, որը ամեն 2 վայրկյանը մեկ ստուգում է, թե արդյոք թղթապանակում նոր ֆայլ է հայտնվել, և տպում նրա անունը։ Ctrl+C-ով կանգնեցնելիս թող տպի «bye» (`trap ... INT`)։ *(Օր 6)*
44. <a id="task-44"></a>Համեմատիր `for arg in "$@"`, `for arg in $@`, `for arg in "$*"`-ը `./t.sh a "b c" d`-ի վրա։ Բացատրիր արդյունքները։ *(Օր 6)*
45. <a id="task-45"></a>Գրիր ռեկուրսիվ ֆունկցիա, որը հաշվում է ֆակտորիալը։ Ինչ է պատահում 21!-ի դեպքում և ինչու (64-bit ամբողջ թվեր)։ *(Օր 6)*
46. <a id="task-46"></a>Վերցրու քո script-երից մեկը և գործարկիր `shellcheck`։ Ուղղիր բոլոր զգուշացումները և բացատրիր, թե ինչ սխալներ էին դրանք։ *(Օր 6)*
47. <a id="task-47"></a>Ընդլայնիր template-ը `-r` option-ով. տեղափոխել ֆայլերը նաև ենթաթղթապանակներից (`find ... -print0` + `while IFS= read -r -d ''`)։ *(Օր 6)*

## Օր 7. Օգտատերեր, սեփականություն և իրավունքներ
48. <a id="task-48"></a>Ստեղծիր երկու օգտատեր և ընդհանուր group։ Կազմակերպիր `/srv/project` թղթապանակ, որտեղ երկուսն էլ կարող են ստեղծել և փոխել ֆայլեր, բայց մնացածները չեն կարող նույնիսկ տեսնել ցանկը (setgid + `2770`)։ *(Օր 7)*
49. <a id="task-49"></a>Ստեղծիր ֆայլ `----r--r--` իրավունքներով և փորձիր կարդալ այն որպես owner։ Բացատրիր, թե ինչու չի ստացվում։ *(Օր 7)*
50. <a id="task-50"></a>Գրիր C++ ծրագիր, որը տպում է real և effective UID-ը։ Տուր նրան setuid բիթ (`sudo chown root prog && sudo chmod u+s prog`) և գործարկիր որպես սովորական օգտատեր։ Ինչ փոխվեց։ (Հետո ջնջիր ծրագիրը։) *(Օր 7)*
51. <a id="task-51"></a>Գտիր քո համակարգի բոլոր setuid ծրագրերը։ Ընտրիր երեքը և պարզիր `man`-ով, թե ինչու են դրանք setuid։ *(Օր 7)*
52. <a id="task-52"></a>`umask 077`-ով ստեղծիր ֆայլ և թղթապանակ։ Ինչ իրավունքներ ստացան։ Ինչու է թղթապանակը `700`, ոչ թե `600`։ *(Օր 7)*
53. <a id="task-53"></a>`sudo -l`. ինչ իրավունքներ ունես `sudo`-ում։ Կարդա `/etc/sudoers`-ը և `/etc/sudoers.d/`-ը։ *(Օր 7)*
54. <a id="task-54"></a>Գրիր ծրագիր, որը կանչում է `system()` օգտատիրոջ մուտքով, և ցույց տուր command injection-ը։ Ուղղիր այն `fork` + `execvp`-ով (Օր 10)։ *(Օր 7)*

## Օր 8. Process-ներ, signal-ներ, service-ներ և փաթեթներ

59. <a id="task-59"></a>Գրիր bash script, որը `trap`-ով որսում է `INT`-ը և `TERM`-ը և ավարտվելուց առաջ ջնջում է իր ժամանակավոր ֆայլը (Օր 6)։ Ստուգիր Ctrl+C-ով և `kill`-ով։ Ինչ է պատահում `kill -9`-ի դեպքում։ *(Օր 8)*

## Օր 10. Process-ներ և thread-եր
72. <a id="task-72"></a>Գրիր ծրագիր, որը `printf("hello")` (առանց `\n`), ապա `fork()`։ Քանի անգամ է տպվում hello։ Ինչու։ Ուղղիր `fflush`-ով։ *(Օր 10)*

75. <a id="task-75"></a>Գործարկիր `counter++` օրինակը առանց mutex-ի 10 անգամ և գրիր արդյունքները։ Ապա `-fsanitize=thread`-ով։ Ինչ է հաղորդում ThreadSanitizer-ը։ *(Օր 10)*

77. <a id="task-77"></a>Իրականացրու ճաշող փիլիսոփաներին `std::thread`-ով և `std::mutex`-ով։ Նախ ստացիր deadlock, ապա ուղղիր այն կողպեքների հերթականությամբ։ *(Օր 10)*
